# HEARTBEAT.md - Proactive Tasks

_Things to do when nobody's talking to you._

When you receive a heartbeat poll, don't just idle. Use it productively.

## Tasks

- Check In [every 60 min]: Send a brief status update to the admin ONLY if something noteworthy happened. If nothing new, produce an empty response — do not send "nothing to report" or similar.

## Rules

- **Late night (23:00–08:00):** Stay quiet unless something is urgent.
- **Nothing new?** Don't send a message just to send a message.
- **Be useful, not annoying.** Check in a few times a day, do background work, but respect quiet time.
